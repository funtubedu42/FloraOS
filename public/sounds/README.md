# 🎵 Emplacement des effets sonores personnalisés de FloraOS

Placez vos fichiers audio directement dans ce dossier (`public/sounds/`).

FloraOS détectera et utilisera automatiquement vos fichiers avec les noms suivants :

### 1. Son d'Erreur & Avertissement
- Nom du fichier : **`error.mp3`** (ou `error.wav` / `error.ogg`)
- Utilisé pour : Alertes système, fichiers protégés, actions refusées, pop-ups d'erreur.

### 2. Son de Notification
- Nom du fichier : **`notification.mp3`** (ou `notification.wav` / `notification.ogg`)
- Utilisé pour : Notifications toast, nouveaux messages, alertes d'information.

### 3. Son d'Action ordinaire / Clic
- Nom du fichier : **`click.mp3`** (ou `click.wav` / `click.ogg`)
- Utilisé pour : Clics sur les boutons, menus contextuels, bascules d'options.

### 4. Son d'Ouverture d'Onglet / Fenêtre
- Nom du fichier : **`window_open.mp3`** (ou `window_open.wav` / `window_open.ogg`)
- Utilisé pour : Déploiement et ouverture des applications sur le bureau.

### 5. Son de Confirmation / Succès
- Nom du fichier : **`success.mp3`** (ou `success.wav` / `success.ogg`)
- Utilisé pour : Enregistrement de document, téléchargement réussi, validation.

### 6. Son de Démarrage
- Nom du fichier : **`startup.mp3`** (ou `startup.wav` / `startup.ogg`)
- Utilisé pour : Lancement initial et démarrage de session FloraOS.

---
*Note : Si un fichier audio n'est pas encore présent, FloraOS utilise automatiquement son synthétiseur Web Audio de secours sans interruption.*
